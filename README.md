# Realme Faces

Android-приложение для Realme Watch 5: каталог циферблатов и импорт/передача файлов IWF.

- Package ID: `com.realme.faces.app`
- Текущая версия: `1.0`
- Минимальная версия Android: 8.0 (API 26)
- Интерфейс: русский, английский и китайский

## Сборка для проверки

В Windows PowerShell из корня проекта:

```powershell
.\gradlew.bat assembleDebug
```

APK для установки находится в `app/build/outputs/apk/debug/`.

## Релизы

Подписанные APK публикуются в разделе GitHub Releases. Ключ подписи хранится отдельно от репозитория и не должен загружаться в GitHub.
