# Realme Faces

Android-приложение для Realme Watch 5: каталог циферблатов, импорт и передача файлов IWF.

- Package ID: `com.realme.faces.app`
- Текущая версия: 1.0
- Минимальная версия Android: 8.0 (API 26)
- Интерфейс: русский, английский и китайский

## Скачать приложение

Откройте [релиз Realme Faces 1.0](https://github.com/zemtcovsk/RealmeFaces/releases/tag/v1.0) и скачайте APK из списка файлов.
